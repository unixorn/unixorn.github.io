Using an Eversecu LCB2 with Frigate#

I wanted to add a security camera over my garage door, and I’m not at all interested in uploading to the cloud so that I’m paying for the privilege of being unable to record video when the internet is out.

The new camera requirements were:

  • RTSP and ONVIF support - it has to work with Frigate.
  • I don’t have ethernet run to the garage, so it has to be a WIFI camera and it can’t require POE.
  • There aren’t any sockets near it on the outside of the house, so it can’t require an adapter either.

After doing some research I settled on an Eversecu LCB2 security camera.

Initial Setup#

I have to give them a thumbs up because of how easy this was.

  1. Install the O-KAM Pro application and set up an account.
  2. Plug the camera and its adapter into a convenient outlet. It’ll speak to you in English when it’s ready to be configured.
  3. Open O-KAM Pro and add a device. It’ll tell you when to point the phone camera at the QR code on the side of the camera.
  4. Give the camera a name and pick which WIFI network to use. It’ll default to whatever SSID your phone is connected to.

Enabling RTSP#

In the phone app, open the camera’s settings and select Device Settings, then select Plaintext Password Settings and pick a password.

Frigate setup#

Here are the Frigate settings I eded up using with the camera after some poking around with nmap.

  eversecu_bulb:
    enabled: true
    ffmpeg:
      inputs:
        # High-resolution stream used for 24/7 recording and high-detail events
        - path: rtsp://admin:{secrets.eversecu_password}@10.1.2.3:10554/tcp/av0_0
          roles:
            - record
        # Low-resolution sub-stream used efficiently for object detection
        - path: rtsp://admin:{secrets.eversecu_password}@10.1.2.3:10554/tcp/av0_1
          roles:
            - detect
    detect:
      enabled: true
      width: 640        # Adjust based on sub-stream native dimensions if needed
      height: 360
      fps: 5
    record:
      enabled: true

Final rating#

It’s a solid low-end camera that works well with Frigate. Easy to configure and easy to install - final installation was borrowing a taller ladder from next door and replacing one of the outdoor spotlight bulbs with the camera. If I had more light fixtures outside the house, I’d happily buy more of these.

Pros#

  • Supports RTSP & ONVIF so it is usable with Frigate
  • Economical - I got mine on the Big River for only $20
  • No wiring required for power or ethernet, it screws into any US-standard light fixture just like a lightbulb
  • Has a color night vision mode
  • Comes with a socket adapter so you can plug the adapter into an outlet and screw the LCB2 into that. You can get everything configured before climbing a ladder to install it.
  • Motorized so you can aim the camera using their phone app
  • 2.4GHz WIFI for better range

Cons#

  • Have to do the initial configuration with a phone application
  • Enabling RTSP wasn’t easy to find.
  • The high resolution stream is only 1080P. But what can you expect for $20?
  • The phone application keeps nagging you to try their cloud service so you can forget you set it up.
  • Boot up is slow. It can take a literal minute to go from power on to it announcing it’s connected to WIFI.
